# TPO Portal — Frontend

React + TypeScript + Vite frontend for the KBP Training & Placement Cell portal.

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

Runs at http://localhost:5173 by default.

## Environment

| Variable | Description |
|----------|-------------|
| `VITE_API_BASE_URL` | Backend API base URL (include `/api` suffix) |

See the [root README](../README.md) and [DEPLOYMENT.md](../DEPLOYMENT.md) for full-stack setup.
